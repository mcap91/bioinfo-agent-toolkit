## What it does

motionbricks-blender is a free, unofficial Blender add-on that imports motion generated by NVIDIA's MotionBricks model (see [[motionbricks]]) as an animated SOMA-rig character inside Blender, via `File › Import › MotionBricks (.npz)` or a MotionBricks tab in the 3D Viewport sidebar. It can optionally build out the rest of the scene too — greybox cubes, a checker floor, a sun, and a camera that follows the character. The imported armature's rest pose matches MotionBricks' own SOMA bind pose and skinning, and every frame is keyed, so the result can be edited, retimed, or baked like any normal Blender action.

## Mechanical details

Three components, each separately licensed: the add-on itself (`addon/motionbricks_importer`, GPL-3.0-or-later, tested on Blender 5.1.2 and 5.2.3 LTS, minimum Blender 4.2); a "walker" script (`walker/mb_walk.py`, Apache-2.0) that takes a small JSON course file (start position/yaw, waypoints, speed, greybox cube layout) and drives MotionBricks to generate a walk using only its built-in SOMA bind pose and its own prior generated poses as targets — no input motion clips at all, which sidesteps MotionBricks' evaluation-only sample-motion license for publishable output; and a "recorder" script (`recorder/mb_record.py`, Apache-2.0) that runs MotionBricks' own Scene Preview demo interactively (WASD to walk, Space to run, walking into boxes triggers jump/vault/duck/sit) or via a scripted timeline, saving the result to .npz at 30 fps — recordings made this way use NVIDIA's evaluation-only sample motions internally and are flagged in the README as for internal testing only, not public release. Setup requires MotionBricks itself (git clone, Git LFS, `uv sync`; NVIDIA RTX GPU for its TensorRT dependency, ~12 GB disk). The repo ships an `AGENTS.md` written for AI coding agents: a user can paste a single prompt into Codex or Claude Code pointing at the repo, and the agent checks for a GPU, asks before installing missing dependencies, clones MotionBricks, generates a walk, installs the add-on, builds a demo scene via `tools/make_demo.py`, and opens it in Blender — automating what the README describes as "a dozen steps" of manual setup. First release v0.1.0 published 2026-10-28; contains no NVIDIA models, sample motions, or meshes itself (those come from the user's own MotionBricks checkout).

## Security

Mixed licensing by component: add-on GPL-3.0-or-later, walker and recorder scripts Apache-2.0. Not affiliated with or endorsed by NVIDIA. The AGENTS.md-driven setup instructs a coding agent to install software and download/run a GPU-dependent third-party model pipeline (MotionBricks) with only a prompt as a gate — review what the agent installs/executes before granting it broad shell permissions, as with any agent-automated local setup. Output using the bundled demo scenes/Smart Primitives draws on NVIDIA's evaluation-only sample motions and is marked unsuitable for public release; only the no-motion-data "walker" path is cleared for published renders per the README.
