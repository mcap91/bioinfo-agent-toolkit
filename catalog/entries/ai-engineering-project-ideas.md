## What it says

Five project ideas for learning AI engineering, sourced from an Instagram reel:

1. **LLM cost autopilot** — automated cost monitoring and optimization for LLM API usage
2. **Semantic caching layer** — cache LLM responses by semantic similarity of inputs rather than exact match, reducing redundant API calls
3. **Model regression detector** — detect when model updates or prompt changes degrade output quality across a test suite
4. **Failure forensics tool** — post-mortem analysis of LLM failures: hallucinations, refusals, format violations, latency spikes
5. **Self-healing technical docs** — documentation that detects drift from the codebase and auto-updates or flags stale sections

## Key takeaways

Each project maps to a real production concern in AI engineering:

- **Cost governance** (1) — overlaps with the agent-cost-governors pattern in this catalog
- **Caching** (2) — semantic similarity search as a cost/latency optimization layer
- **Quality assurance** (3) — regression testing adapted for non-deterministic outputs
- **Observability** (4) — structured failure analysis for LLM-powered systems
- **Maintenance** (5) — keeping documentation synchronized with rapidly changing AI codebases
