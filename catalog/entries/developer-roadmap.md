## What it does

The source content for roadmap.sh: a large set of interactive, node-based roadmaps and guides that map learning paths for developer roles and technologies (e.g. frontend, backend, DevOps, full-stack, AI/data, plus role- and skill-based roadmaps). Each roadmap is an interactive graph on the website whose nodes are clickable; the text behind a node lives in a Markdown file at `roadmaps/<roadmap-slug>/content/<topic-slug>@<node-id>.md`. The `<node-id>` in the filename is what binds the content to its node, so filenames must be preserved. Merged content changes sync to the website automatically. `scripts/` holds maintainer sync tooling.

## Provenance

This queue URL, `nilbuild/developer-roadmap`, is a **fork** of the canonical upstream `kamranahmedse/developer-roadmap` (the project behind roadmap.sh, ~360k stars / ~45k forks). The fork tracks upstream via automated `chore: update roadmap content json` PRs generated by upstream's `refresh-roadmap-content-json` workflow and periodic `Merge branch 'kamranahmedse:master'` commits. For canonical/current content, prefer the upstream repository and the roadmap.sh website; this fork can drift from upstream between syncs.

## Mechanical details

- Content format: one Markdown file per roadmap topic node; the interactive roadmaps render on roadmap.sh, not in the repo.
- Shallow clone documented: `git clone <repo> --depth 1`.
- Contribution model: read-only GitHub forks (via the Fork button) are explicitly permitted for contributing back; edits flow upstream and then to the website.
