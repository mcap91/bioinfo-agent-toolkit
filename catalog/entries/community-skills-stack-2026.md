## What it does

Community-curated Reddit post listing a practitioner's actual daily-use agent skills stack in 2026, with verified install commands. Organized by domain:

**Engineering:**
- `addyosmani/agent-skills --skill code-review-and-quality` — structured review across correctness, readability, architecture, security, performance
- `ai-evals-course/evals-skills` — audits eval pipelines, discovers failure modes from traces, workflows for product-specific evals
- `anthropics/skills --skill mcp-builder` — guides building MCP servers
- `CodeAlive-AI/ai-driven-development --skill prompt-engineering` — diagnoses prompting problems, chooses techniques, avoids hallucinations/structure/security mistakes
- `obra/superpowers-marketplace` (plugin) — disciplined dev workflow with planning, TDD, debugging, task-execution patterns
- `anthropics/skills --skill webapp-testing` — Playwright-based browser testing with screenshots and log inspection

**Design:**
- `anthropics/skills --skill canvas-design` — design briefs to original PNG/PDF artwork
- `anthropics/skills --skill frontend-design` — production-quality frontend design over generic layouts

**Communications:**
- `@atomicmail/agent-skill-github` — gives agent its own email inbox for autonomous read/send/react
- `anthropics/skills --skill internal-comms` — status reports, leadership updates, incident reports, newsletters

**Memory:**
- `kepano/obsidian-skills` — Obsidian-specific knowledge for Markdown, Bases, JSON Canvas, CLI workflows
- `OthmanAdi/planning-with-files --skill planning-with-files` — stores plan/findings/progress in files for recovery after context loss

**Automation:**
- `vercel-labs/agent-browser` — real browser automation for navigation, forms, screenshots, data extraction, testing

**Growth:**
- `kostja94/marketing-skills --skill seo-audit` — technical SEO, indexing, on-page, content, off-page audit

**Discovery:**
- `anthropics/skills --skill skill-creator` — create new skills, run evaluations, benchmark, optimize trigger descriptions
- `skills.sh/pwguler/skills` — custom task observer (community-recommended)
