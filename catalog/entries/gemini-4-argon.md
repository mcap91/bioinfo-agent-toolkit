## What it does

Gemini 4 Argon is Google's newest frontier large language model, announced September 30, 2026 as Google's most capable model yet. It was built to sustain deep reasoning across complex, long-horizon workflows — coding tasks from everyday debugging to large-scale codebase migrations, algorithm design, financial-report analysis, deck creation from scattered sources, and interactive 3D-model building. Google tuned Argon specifically for cybersecurity defense and initially rolled it out to trusted cyber defenders through its Fairwind Program before wider release.

Broader availability followed October 13, 2026: global rollout in the Gemini app for Google AI Pro & Ultra subscribers, API access via AI Studio and the Gemini platform for developers and enterprises, availability in Google Antigravity (Google's agentic coding interface, also brought into the Gemini macOS app), and general availability on Google Cloud. Google reported Argon scoring higher than OpenAI's GPT-6 Astra and Anthropic's Fable/Opus models on third-party benchmark indexes it cited (Vals AI), a 14% accuracy improvement on enterprise knowledge work versus Gemini 3.1 Pro, and a drop in coding "shortcut attempts" to 2%, its best result against prior Gemini models. Output capacity was raised to up to 1 million tokens, up from a prior 64,000-token limit.

## Mechanical details

- Access: Gemini app (AI Pro/Ultra subscribers), API via Google AI Studio and the Gemini platform, Google Antigravity, Google Cloud, AI Mode in Search
- Introductory API pricing (through 2026-11-30): $2 per 1M input tokens, $10 per 1M output tokens; cached input tokens discounted 95%
- A version without cyber guardrails was separately made available to a select set of trusted defenders for full-breadth cybersecurity-capability testing

## Security

Proprietary, closed-source, hosted model — no independently verifiable source or weights. Google-reported safety testing and guardrails were applied during a pre-release "post-training" phase with an initial trusted-tester cohort (Fairwind Program) before general availability.
