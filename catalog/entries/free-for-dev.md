## What it does

Curated, community-maintained directory of cloud and developer services offering free tiers. Categories include:

- Cloud providers (compute, storage, functions)
- CI/CD platforms
- Databases (hosted PostgreSQL, Redis, etc.)
- Monitoring and logging
- Email and messaging
- DNS, CDN, SSL
- Auth and identity
- Search (Algolia, Meilisearch hosted, etc.)
- And many more

Hosted on GitHub with regular contributions. Useful for bootstrapping projects without upfront infrastructure costs.

## Assessment

Good reference for standing up development/staging infrastructure for catalog tools or agent deployments without cost. The free tiers are often sufficient for personal projects and early prototyping.
