## What it does

{Shan, Shui}* generates infinite procedural Chinese landscape paintings in the browser, output as Scalable Vector Graphics (SVG). Inspired by traditional Chinese landscape scrolls, it uses noise and mathematical functions to model mountains, trees, and other landscape elements from scratch.

Written entirely in JavaScript. No external dependencies. Runs client-side in any modern browser.

## Security

License not stated in README. Pure client-side JavaScript — no network calls, no data collection.
