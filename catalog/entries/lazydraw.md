## What it does / What it says

lazydraw is a terminal ASCII editor for drawing quick diagrams and sketches, with options to export to text files or copy to the clipboard. It runs as a full-screen TUI built on the OpenTUI (sst/opentui) terminal engine and is explicitly modeled on the browser tool ASCIIFlow — the author ported ASCIIFlow's core drawing logic (glyph connection, snapping, line routing, box/line/select/move tools) into `src/core`, a pure-TypeScript layer with no terminal-specific code, and layered an OpenTUI front end (`src/tui`) on top. The stated motivation (from the source post) is describing diagrams/UIs to a coding agent visually, from the terminal, without leaving it.

## Differentiators / Key takeaways

- Mouse-driven toolbar: `box`, `select`, `arrow`, `line`, `text`, `eraser`, plus undo/redo, settings, and help. `select` can move a box with attached arrows, resize/reshape lines, or drag-select empty space; `eraser` detaches from any line it touches.
- Export: extended or basic (plain-ASCII) character sets, 11 comment styles, optional Markdown code-fence wrapping, preview before saving, clipboard copy, or file save (`-o`). Export also runs headless via CLI (`lazydraw export <name> --basic --comment hashes --fenced -o diagram.txt`) without opening the UI.
- Multiple named drawings per install (`lazydraw <name>` opens or creates by name; `lazydraw list` enumerates them; `lazydraw ./diagram.ld.json` opens by path; `--import notes.txt` imports plain text). Drawings autosave 500ms after each change and again on quit.
- Theming reads the terminal's own OSC 10/11/4 color-query palette by default so the UI blends with the user's terminal; also ships 10 IDE-style themes (dracula, nord, tokyo-night, catppuccin, one-dark, gruvbox, monokai, night-owl, solarized-dark, github-light). Grid rendering uses a Unicode cell-edge glyph (U+1FB7C) with a `checker` fallback for terminals that don't render it correctly.
- Test suite includes fixture-based regression tests replayed against ASCIIFlow's own upstream code (`test/fixtures/asciiflow`, regenerated by cloning `lewish/asciiflow` and running a capture script) and `test/upstream`, which runs ASCIIFlow's own spec files against lazydraw's core through a compatibility shim — an explicit behavioral-parity check against the tool it's modeled on.
- A third-party fork exists: `ioma8/rsdia`, a Rust TUI/CLI rewrite of lazydraw with the same box/arrow/line/label diagramming model plus undo, pan, mouse, and clipboard support — not evaluated as part of this entry.
- Acknowledges and explicitly differentiates from `benvinegar/termdraw` (an existing terminal ASCII illustrator the author judged unsuited to "structured sketches like diagrams and UIs") and from ASCIIFlow (the browser tool it ports).

## Mechanical details / What to adopt

Requires the Bun runtime >= 1.3 (`engines.bun: ">=1.3"`) and a terminal with mouse support. Install: `bun install -g lazydraw` then run `lazydraw`; `npm install -g lazydraw` also works and typically lands on `PATH` already; `bunx lazydraw` runs without installing. The npm `bin` entry (`lazydraw: src/cli.ts`) points directly at a TypeScript source file rather than a compiled artifact — global bun/npm installs execute it via Bun's native TS runtime, not a build step (a standalone compiled binary is only produced locally via `bun run build`, output to `dist/lazydraw`). Single runtime dependency: `@opentui/core ^0.5.11`. `prepublishOnly` runs `bun run typecheck && bun test` before publish. Config/data: drawings in `${XDG_DATA_HOME:-~/.local/share}/lazydraw/drawings/<name>.ld.json`, config in `${XDG_CONFIG_HOME:-~/.config}/lazydraw/config.json`. tmux requires `set -g mouse on` (and `set -g set-clipboard on` for OSC 52 clipboard copy); macOS needs "Option as Meta" for Alt+digit tool shortcuts.

Package published to npm 2026-09-19 (v0.1.0, then v0.1.1 same day with a description/README fix); this is the only source available at review time.

## Security

MIT license (per npm registry `package.json`). Published by npm user `mpospirit` (author name Çağrı Gökpunar, email `cagri@mpospirit.com`); single maintainer, no co-maintainers listed. The linked GitHub repository (`github.com/mpospirit/lazydraw`) returns HTTP 404 as of this review — the source post states the author's GitHub account was suspended shortly after posting ("GitHub suspended my account for some reason"), and a contemporaneous Hacker News comment (https://news.ycombinator.com/item?id=49800172) independently corroborates the repo becoming unavailable within hours of the original post; neither the suspension reason nor whether it is account-wide or repo-specific could be verified from available sources. Practical effect: no visible commit history, issue tracker, CI configuration, contributor count, or star/fork signal exists outside the npm tarball itself — provenance rests entirely on the npm registry listing and its embedded README. Only one runtime dependency (`@opentui/core`), reducing supply-chain surface, but it has not been independently audited here. No known CVEs or vulnerability reports found; package is 6 days old at time of review with no external adoption signal beyond the single Hacker News thread. Users should weigh the unresolved GitHub-suspension circumstance before installing or granting it filesystem/clipboard access.
