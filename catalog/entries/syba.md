## What it does

SYBA classifies organic compounds as easy-to-synthesize (ES) or hard-to-synthesize (HS)
using a Bayesian fragment scoring approach. Each molecule is decomposed into ECFP4-like
fragments, and each fragment receives a pre-computed score based on its relative frequency
in ES compounds (random ZINC15 selection) versus HS compounds (generated by the Nonpher
approach). Fragment scores are summed to produce the final SYBA score.

- **Positive score:** easy to synthesize
- **Negative score:** hard to synthesize
- Score magnitude reflects classifier confidence, not a direct measure of synthetic difficulty

## Usage

```bash
# CLI
syba input.csv output.csv
```

```python
from syba.syba import SybaClassifier

syba = SybaClassifier()
syba.fitDefaultScore()
score = syba.predict("O=C(C)Oc1ccccc1C(=O)O")
```

Also accepts RDKit Mol objects via `syba.predict(mol=mol)`.
