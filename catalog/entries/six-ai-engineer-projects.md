## What it says

A list pairing each of six AI-engineer skills with a project defined as "a company problem with a name, not a tutorial":

1. **RAG → Fieldnote** — field-service assistant that answers from the chart on page 112 instead of a caption of it (layout-aware retrieval, not text-only).
2. **Agents → Casefile** — claims triage with typed handoffs, a cost ceiling, and a human before any payout.
3. **LLMOps → Warmstart** — three-layer cache over 400k support questions/month with the false-hit rate measured, not assumed.
4. **Evals → Groundtruth** — eval harness for legal research that fails the pull request when recall drops.
5. **Fine-tuning → Slotfill** — LoRA adapter on 40k freight invoices, benchmarked against the prompt it is trying to replace.
6. **Guardrails → Doorman** — recruiting agent that survives injection hidden inside a candidate's resume.

## Key takeaways

- Each project embeds its own success metric (false-hit rate measured, PR fails on recall drop, benchmark vs the replaced prompt, survives injection) — the skill is demonstrated by the gate, not the demo.
- Useful as a template for scoping portfolio or interview projects: name the company problem, define the failure condition, build to that.
