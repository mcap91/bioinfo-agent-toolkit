## What it does

Hacksplaining provides 45 interactive lessons on web application security vulnerabilities. Each lesson (15-30 minutes) features:

- Character-driven narratives with attacker personas (The Savant, The Cowboy, The Hacker, The Specialist, The Mark)
- Multi-language code examples: vulnerable and secure code in Python, JavaScript, Java, Go
- Quizzes after each lesson with progress tracking
- Coverage from OWASP classics (SQL injection, XSS, CSRF, auth flaws) through AI-era threats like prompt injection

Free for personal use, no credit card required. Team plans include dashboards, SSO, and compliance reporting. Used at Google, IBM, Microsoft, Amazon, Intel, and others (500K+ registered users as of July 2026).
