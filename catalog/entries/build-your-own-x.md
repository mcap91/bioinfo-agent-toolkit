## What it does

A curated directory of "build it from scratch" tutorials organized by technology category. Each entry links to an external tutorial that walks through reimplementing a real system (database, compiler, OS kernel, neural network, web server, etc.) in a specific language. Categories include 3D renderers, AI models, BitTorrent clients, blockchains, bots, CLIs, databases, Docker, emulators, frontend frameworks, games, Git, memory allocators, network stacks, neural networks, operating systems, physics engines, programming languages, regex engines, search engines, shells, template engines, text editors, visual recognition, voxel engines, web browsers, and web servers.

Languages represented include C, C++, C#, Python, JavaScript, TypeScript, Go, Rust, Ruby, Java, Haskell, Elixir, OCaml, Nim, Lua, and others. The repository has 350K+ GitHub stars and is maintained by CodeCrafters, Inc.

## Assessment

Learning reference — not a tool, skill, or agent component. Useful when needing to understand a system's internals (e.g., before building a tool that wraps or extends that system) or when looking for implementation exercises in a specific language. The "Build your own Neural Network" and "Build your own Database" sections are directly relevant to data science and bioinformatics tooling contexts.

## Security

CC0-licensed (public domain dedication). The repository itself contains only links — no executable code. Security properties of linked tutorials vary by author.
