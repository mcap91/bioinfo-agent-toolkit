## Caption

Papermorph: The AI That Animates Your Textbooks

Papermorph is the AI skill that turns static PDFs into living, narrated web experiences. It solves the problem of dry, unengaging textbooks by transforming flat pages into interactive lessons with voice narration and animated visuals. The most surprising part is that it does this entirely by generating code and storyboards, without needing any image generation models. You just feed it a book, and it builds a browsable website where you can watch lessons and take quizzes right in your browser. If you want to make your own course materials feel less like homework and more like a movie, this is the tool to check out.

Open source: dozentwelve/papermorph

## Key claims

- Papermorph is an AI skill that turns static PDFs into living, narrated web experiences
- It transforms flat textbook pages into interactive lessons with voice narration and animated visuals
- It generates code and storyboards entirely without using any image generation models
- Users feed it a book and it builds a browsable website for watching lessons and taking quizzes
- The pipeline is PDF -> Book plan -> Storyboards -> Narration -> Animation & quizzes
- Currently only works with Opus 5.5, with no image models, multilingual support, or background music yet
- Planned features include image models and storyboarding for interactive picture books and humanities documentaries
- It is open source at github.com/dozentwelve/papermorph
