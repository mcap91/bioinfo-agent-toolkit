## Key claims

- An entire game's assets can be textured using a single low-resolution gradient map image.
- This works because Blender's built-in linear interpolation smooths out the pixelated gradient map.
- Gradient maps can be found by searching 'gradient' on itch.io, or made yourself.
- In Blender, you add the gradient texture to a material, set roughness to 1, lock the UV view to front orthographic, select all, project UVs from view, flatten the UV map on the x-axis, then scale and position it to pick a color from the gradient.
- Different parts of a mesh can be selected in edit mode and re-unwrapped individually to assign different colors from the same gradient map.
- For the sword blade, rotating the model 90 degrees, projecting from view, and using a mirror modifier creates a gradient radiating out from the center.
